## 📌 Overview

This repository presents the research work titled:

> **Cross-Domain Cyber Awareness Using Signal Intelligence Techniques**

The work introduces a framework called **Cyber Awareness via Residual Signals (CARS)** for improving cyber situational awareness using signal intelligence concepts.

The main idea is to treat network activity as a time-varying signal, establish a normal behavioral baseline, calculate residual deviations from that baseline, extract interpretable features, and convert those deviations into meaningful cyber awareness indicators.

The paper was presented at **IEEE UEMCON 2026**.

## 🎯 Research Objective

The main objective of this work is to develop an interpretable cyber awareness framework that can identify meaningful changes in network behavior without relying entirely on complex black-box detection systems.

The proposed CARS framework uses residual signal analysis to highlight deviations between observed network activity and expected baseline behavior.

These deviations are then transformed into interpretable indicators that can support cyber monitoring, anomaly detection, and situational awareness.
